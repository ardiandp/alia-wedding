PRD — Wedding Venue & Wedding Organizer

Platform: Web
Backend: Laravel
Database: MySQL
Frontend: Blade + Tailwind CSS / Bootstrap
Authentication: Laravel Breeze/Fortify
Admin: Custom Admin Dashboard
Storage: Local/S3-compatible storage
Notification: WhatsApp + Email
Maps: Google Maps
SEO: Laravel SEO-friendly routing + metadata

27. Performance

Karena website akan banyak foto/video, ini penting.

Gunakan:

WebP/AVIF
Lazy loading
Responsive image
Image thumbnail
CDN
Browser caching
Database indexing
Query eager loading
Laravel Cache

Video hero sebaiknya tidak langsung memakai file video super besar. Gunakan compressed video dan fallback image.
